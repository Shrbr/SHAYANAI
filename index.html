Separate from your chat API above — image generation almost always needs a different provider (e.g. OpenAI), since most chat-only APIs like the free OpenRouter tier don't support it.

App lock

Protect your chats, memory, settings, API keys and attached files with a passcode. Everything is encrypted in this browser (AES-256) and the passcode itself is never stored — if you forget it, the data can't be recovered.

Privacy

Conversations, settings and attached files live only in this browser. Text leaves your device only when you choose an API connection, web search or image generation — and then only to that service.

About
